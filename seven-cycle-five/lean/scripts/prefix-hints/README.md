# Adjacent prefix index

The Stage 4 join indexes full three-dimensional supports by an ordered triple of planar masks. The first two masks are the unions of heights 0–1 and 1–2. The third is height 1. The hint keeps a sparse subset of these domains in memory. The verified join forwards every absent key to its terminal check.

From the Lean project directory, the following commands rebuild the hint from the released C++ drivers and check every extracted key with the Lean implementation. The first argument to the extractor is the published code directory that contains `round25` and `round26`. It uses the shared release atlas and the ten adjacent profiles. The scratch directory must have space for the binary support pairs and the two temporary intermediate files.

```sh
python3 scripts/prefix-hints/extract.py /path/to/release/code /tmp/seven-prefixes
python3 scripts/prefix-hints/generate.py /tmp/seven-prefixes --binary /tmp/seven-prefixes/reference.bits
lake build SevenCycle.Adjacent.PrefixHint SevenCyclePrefixRuntime:shared
lake env lean --load-dynlib=.lake/build/lib/libseven_x2dcycle_SevenCyclePrefixRuntime.so \
  --run scripts/prefix-hints/Verify.lean /tmp/seven-prefixes/reference.bits /tmp/seven-prefixes/*/hints.bin
```

The ten checked input files contain 527,498 records and 114,433 distinct triples. The resulting packed reference has 216,869 set bits and SHA-256 `b45eba698fc108849401f9ce91aa6c5e11e0f060316d224871ad8339e8f5acba`.

The generator sets two of 2²¹ bits for each triple using the low 21 bits and high-half low 21 bits of a 64-bit digest. Each URL-safe alphabet character stores six consecutive bits in little-endian order. The final character stores two bits. The decoder indexes digits directly. Identical records and repeated hash positions leave the generated bytes unchanged, so enumeration order is immaterial.
